Thumbnails

A square image tile with optional overlays: a caption along the bottom, a label top-left and a value top-right. For galleries, rows of small images and image cells in tables.

Gallery

Fluid thumbnails fill the cells of a .kt-thumb-grid. Put an <img> directly inside the tile; these demos use .kt-media-placeholder instead. Use an <a> or <button> for a clickable tile.

With a tooltip

The tile has no overflow: hidden, so a .kt-tooltip on it is not clipped. Useful for small tiles that have no room for a title.

Class reference

ClassDescription
.kt-thumbSquare tile; fluid width by default. Holds an <img> or a .kt-media-placeholder. As <a> / <button> (or with --interactive) it gets a hover edge.
.kt-thumb--{sm|md|lg}Fixed 40 / 48 / 64px.
--kt-thumb-sizeCustom fixed size.
.kt-thumb__captionText along the bottom on a fade to dark.
.kt-thumb__badgeSmall label, top-left (e.g. a rank).
.kt-thumb__cornerSmall value, top-right (e.g. a count or score).
.kt-thumb-gridAuto-fill gallery grid of fluid tiles. Tune with --kt-thumb-min.
--kt-scrimThe dark veil behind overlay text (same in both themes).
