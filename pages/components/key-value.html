Key-value list

Labels on the left, values on the right. Use it for detail panels, summaries and info boxes next to charts.

Basic

Use a <dl> with one .kt-kv__row per pair. Values are bold, right-aligned and use fixed-width digits.

Label one
1,204.50
Label two
38%
Label three

Groups & totals

Use .kt-kv__sep to separate groups of rows and --total to emphasize a final row.

Class reference

ClassDescription
.kt-kvThe list (use on <dl>).
.kt-kv__rowOne <dt> + <dd> pair.
.kt-kv--divided / --looseHairlines between rows / more vertical padding.
.kt-kv__sepSeparator between groups.
.kt-kv__row--totalEmphasized totals row.
