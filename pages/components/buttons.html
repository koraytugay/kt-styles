Components

Buttons

One button class with variants, sizes and shapes. It works on <button> and <a>, and it's the same height as inputs and selects, so a toolbar lines up.

Variants

Default for ordinary actions, primary for the main action (at most one per area), accent for a highlighted secondary action, ghost for low emphasis, and danger for destructive actions.

Sizes

Shapes

--pill rounds the ends, --icon makes the button square (always give it an aria-label), and --block makes it full width.

With icon

Put an emoji or inline SVG before the label. The gap is built in.

States

Disable with the disabled attribute (on links, use aria-disabled="true"). For a busy state, put a small spinner inside.
