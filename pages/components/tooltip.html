Components

Tooltip

A short text bubble on hover or keyboard focus. CSS only: the text comes from data-tooltip.

Placement

Above the element by default; .kt-tooltip--bottom puts it below. The class only adds position: relative, so it doesn't change the element's layout.

Label

Notes

  • Keep the text to a few words on one line; it doesn't wrap.
  • A parent with overflow: hidden clips the bubble.
  • An empty or missing data-tooltip shows nothing, so scripts can always add the class.
  • Don't put essential information only in a tooltip: touch screens have no hover.

Class reference

ClassDescription
.kt-tooltip + data-tooltip="…"Shows the attribute's text above the element on hover / focus.
.kt-tooltip--bottomShows it below instead.
