Toast

A short message that floats in the bottom-right corner (full width at the bottom on phones) and goes away on its own. Your script appends a .kt-toast to a .kt-toast-stack on <body>, adds .is-visible on the next frame, and removes it after a few seconds. The previews below use --static so they stay in the page.

Class reference

ClassDescription
.kt-alert (+ --info|success|warning|danger)Tinted message box. Child: __title. Modifier: --center.
.kt-spinner / --sm36px spinner / inline spinner in the current text color.
.kt-loadingCentered spinner + message block.
.kt-emptyCentered empty state. Children: __icon, __title, a <p> and an optional .kt-btn.
.kt-toast-stackFixed bottom-right container for toasts (bottom, full width on phones). --static keeps it in the page flow.
.kt-toast (+ --success|danger)Floating message; hidden until .is-visible.
