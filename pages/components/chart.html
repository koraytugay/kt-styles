Components

Chart furniture

Everything around a chart except the chart itself: the plot + side-panel layout, the readout panel that shows the hovered data point, and the legend. Draw the chart with SVG or a library.

Layout with readout

The plot takes the remaining width, the readout sits in a 310px side column (it moves below the plot on narrow screens). While the user hovers the chart, add .is-active to the readout and fill it with that point's values; on leave, show the latest point again.

ClassDescription
