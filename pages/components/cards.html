Media card

An image slot with optional badges over it, then a title, a subtitle and a two-column meta grid. The meta grid sticks to the bottom of the card, so cards in the same row line up. Use <a> as the root element to make the whole card clickable.

Collection grid

Media cards inside a .kt-grid. For the other view modes, add .kt-grid--compact or .kt-grid--list to the grid. The cards adjust on their own, with no changes to the card markup. Try the switcher.

Class reference

Card

ClassDescription
.kt-cardSurface panel.
.kt-card__header / __body / __footerPadded slots with dividers.
.kt-card__title / __subtitleTitle text styles.
.kt-card__actionsRight-aligned area in the header.
.kt-card--paddedAdds padding to the card itself, for cards with no slots.
.kt-card--interactivePointer cursor; lifts on hover.
.kt-card--flatNo shadow.

Stat

ClassDescription
.kt-stat-rowRow of stat tiles; as many fit as the width allows.
.kt-statTile. Children: __value, __label, __sub (muted secondary line), __delta.
.kt-stat__delta--{up|down}Green / red change indicator.
.kt-stat--leftLeft-aligned tile.
.kt-stat--insetSmall metric box inside a card or modal (sunken, left aligned, no shadow).

Media card

ClassDescription
.kt-media-cardRoot element. Use <a> (or add --interactive) so the card lifts on hover.
.kt-media-card__mediaImage slot. Holds an <img> or a .kt-media-placeholder.
.kt-media-card__badgesBadges stacked in the image's top-left corner.
.kt-media-card__cornerSlot in the image's top-right corner.
.kt-media-card__bodyText area. Children: __title, __subtitle, __meta.
.kt-meta-item / --fullOne cell of the meta grid / a cell spanning both columns.
.kt-media-card--squareSquare (1:1) image.
.kt-media-card--horizontalLays out a single card as a row.
.kt-media-placeholderGradient fallback for missing images. Set the colors with --kt-ph-from / --kt-ph-to.
--kt-media-heightImage height (default 220px).
--kt-media-positionHow the image is anchored when cropped (default center; use top for posters / box art).

Grid

ClassDescription
.kt-gridGrid that fits as many columns as the width allows. Tune it with --kt-grid-min and --kt-grid-gap. Shows 2 columns on mobile.
.kt-grid--compact / --listCompact and list view modes. Media cards adjust automatically.
.kt-grid--{2|3|4}Fixed number of columns.
