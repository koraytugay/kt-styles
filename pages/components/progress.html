Progress

A rounded track with colored segments. One segment shows a single share or completion; several show a stacked breakdown.

Single value

Set the segment's width inline. The default color is the accent.

Sizes

Stacked breakdown

Several segments side by side. Give each a color with --kt-progress-color (or a tone class) and pair it with a legend.
