Tables

Data tables with small uppercase headers. Wrap the table in .kt-table-wrap for the card frame and horizontal scrolling on narrow screens.

Basic table

Add .kt-num to numeric cells, including the header cell, to right-align them with fixed-width digits.

Sortable headers

Put aria-sort on a header cell to show sort arrows: none shows a faint ↕, ascending ▲, descending ▼. Sorting itself is up to your script.

Class reference

ClassDescription
