Foundations

Layout

A page container, a responsive grid and three flex helpers. Together they cover almost every page layout.

Container

.kt-container centers the page content at up to 1350px wide, with side padding. Wrap every page in one.

Grid

.kt-grid fits as many columns as the width allows, each at least --kt-grid-min wide (210px by default). On phones it always shows 2 columns.

Fit

By default empty columns are kept, so items in a short row keep the same width as in a full row. --fit stretches them to fill the row instead.

Cluster

A horizontal row that wraps, with items vertically centered. Use it for groups of buttons, badges and controls.

Split

Pushes its children to opposite ends, for example a title on the left and actions on the right. It wraps on narrow screens.

Class reference

ClassDescription
.kt-containerCentered page wrapper, up to 1350px wide.
.kt-gridResponsive grid. Variables: --kt-grid-min, --kt-grid-gap.
.kt-grid--fitStretch items to fill the row when there are fewer items than columns.
.kt-grid--{2|3|4}Fixed number of columns (2 on phones).
.kt-grid--compact / --listView modes for card grids.
.kt-stackVertical flex with gap (--kt-gap).
.kt-clusterWrapping horizontal flex with gap (--kt-gap).
.kt-splitChildren pushed to opposite ends.
.kt-mt-{0|1|2|3|4|5|6|8} / .kt-mb-{…} / .kt-m-0Top / bottom margin on the spacing scale (0, 4, 8, 12, 16, 20, 24, 32px) / no margin.
.kt-ml-autoPushes one item to the end of a flex row.
.kt-measureLimits text width to about 72 characters for readability.
