Getting Started

Overview

The reference for kt-styles: every element, live, in light and dark mode. Pick an element from the sidebar; the markup to copy is in that page's source.

Usage

Link the stylesheet in the page's <head>:

<link rel="stylesheet" href="path/to/kt-styles/css/kt.css">

Then build the page with kt- classes and --kt- variables. Because of the prefix, the library can also be added to an existing page without clashing with the styles it already has.

Dark mode: document.documentElement.dataset.theme = 'dark'. For older pages, adding the dark-mode class to body also works.
